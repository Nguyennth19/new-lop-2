## 2. Adapter source sketch (chưa thực thi / chưa có mã tích hợp)
Chỉ minh họa interface đã có, không cung cấp runnable writer hoặc shortcut bật grant. Provider adapter chỉ có quyền truy cập property key cố định của scope đã được kiểm tra; scope & allowlist được review bên ngoài, không lấy từ client. Trong N7 lock, đọc property đúng key; nếu absent/corrupt thì UNKNOWN, không set READY. Khi READY hợp lệ, ghi RESERVED với immutable record, đọc lại raw exact, đọc lại grant + baseline dưới cùng lock, mới cho N7 append/flush/readback. Sau xác minh mark VERIFIED; nếu không xác minh được trả COMMIT_UNKNOWN, writes:null, retryAllowed:false. Read-only reconciliation sau revoke/expiry không gọi setProperty. Không nhúng property secrets, grant thật hoặc owner email trong repo.
- Draft binding (non-executable pseudocode): store = approvedEpochPropertyStore(scriptProperties, exactKey); ledger = M4-compatible state transitions(scope, store, backupRead, currentGrant); return n7TestExecute_(intent, depsWithLedger, settings); read-only reconcile follows M4 full snapshot + original batch checks. M4 synthetic functions remain intact; actual provider scope validation + epoch binding + guard + narrow entrypoint requires source review. No runtime source edits in this step.
- Store key N12_ATTEMPT_<scopeDigest>, grant key N12_GRANT_<scopeDigest>; distinct epochs, immutable attempt once reserved; no reset; receipt mapping N11_M1_M2_RECEIPT_V1 with requestId/idempotencyKey/executionId/original batch_id/eventId/intentDigest/journalDigest. Preserve M4 envelope integrity; checksum not a signature. A failed property write ack is uncertainty, not proof of noncommit. Replay after later append can fail full snapshot comparison; use independent epochs/targets for proofs, not relax verifier. Quotas and byte length must be verified against real provider before grant. External editor rollback of both stores remains open. Properties are shared among script editors, not independent trust anchor.
