## 3. Công cụ nhập SVG theo batch TEST-only

- `qa/g7-4-b6-batch-import/stage-batch.cjs` hỗ trợ `dry-run` mặc định, `--apply` vào vùng **quarantine local**, `--rollback` bằng batch ID.
- Kiểm SHA256 từng byte, source commit SHA-40, MIT/LICENSE, ID trùng, SHA trùng, source path, đường dẫn cục bộ, SVG allowlist thận trọng (quét thô), chỉ chấp nhận 1–100 asset/batch.
- Nhập cả lô theo nguyên tắc **all-or-nothing** vào thư mục mới và ghi manifest riêng với `runtimeEnabled=false`, `productionActivation=false`, `visualQa=OWNER_PENDING`, `countQa=NOT_APPROVED`.
- Không sửa manifest chính, không đồng bộ Drive, không kết nối CDN, không kích hoạt runtime. Rollback chỉ xóa batch cách ly do chính công cụ tạo, qua marker.
- **Giới hạn an toàn:** regex SVG là bộ chặn sơ bộ, không thay cho kiểm tra XML/security sâu, kiểm toàn bộ giấy phép/nguồn, hoặc phê duyệt nội dung. Không cho xuất quarantine thành registry chính thức trước khi đi qua các cổng đó.

Lệnh (trong working copy GitHub):
```bash
node qa/g7-4-b6-batch-import/stage-batch.cjs --batch qa/g7-4-b6-batch-import/batch.example.json --source-dir /path/to/local-source --existing hinh-anh/svg-fallback/fluent-emoji-flat/v1/manifest.v1.json --out /tmp/g74-quarantine
# Sau khi dry-run PASS, chỉ trên TEST:
node qa/g7-4-b6-batch-import/stage-batch.cjs --batch qa/g7-4-b6-batch-import/batch.example.json --source-dir /path/to/local-source --existing hinh-anh/svg-fallback/fluent-emoji-flat/v1/manifest.v1.json --out /tmp/g74-quarantine --apply
# Phục hồi batch đã staged:
node qa/g7-4-b6-batch-import/stage-batch.cjs --out /tmp/g74-quarantine --rollback <batch_id>
```
