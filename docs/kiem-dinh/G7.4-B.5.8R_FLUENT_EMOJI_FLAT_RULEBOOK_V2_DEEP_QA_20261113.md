- Microsoft chính thức: https://github.com/microsoft/fluentui-emoji; LICENSE MIT: https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE; Iconify index: https://github.com/iconify/icon-sets/blob/master/collections.md. Giữ đầy đủ bản quyền và LICENSE.
- WebP 288 ID đã nghiệm thu nhãn ưu tiên; svg màu **local, SHA-pinned, manifest allowlist**, fallback cuối cùng HTML placeholder; Iconify API chỉ để tra cứu/test, không dùng như bên thứ ba bắt buộc tại runtime.
- 40–60 SVG chỉ là **quy mô pilot dự kiến**, CHƯA tải/nhập hay nghiệm thu file nào; phải có official upstream commit và SHA256 từng icon, XML/SVG security linter, visual QA 32–64px và owner signoff.
- Để dựng đúng số lượng: `COUNT_SAFE_APPROVED`, `objectsPerAsset=1`, tổng groups đúng, ảnh vật đơn; logo/sách mở/chồng sách/multiple-object không được lặp vô tội vạ.
- Đơn vị đo, thước, đồng hồ, hình học vẫn dùng SVG toán học tham số, không thay bởi emoji. B.5.8 hai asset sách/gà tiếp tục `TEST_CANDIDATE`.
