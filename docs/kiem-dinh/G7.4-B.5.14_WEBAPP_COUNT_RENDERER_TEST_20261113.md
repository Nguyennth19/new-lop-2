## 3. Hợp đồng tính năng: fail closed

Để hiển thị thực hành B.5.14 cần **cả ba điều kiện đồng thời**:

1. Trên **Apps Script project TEST tách biệt** phải có Script Properties `G74_B514_SCOPE=ISOLATED_TEST_WEBAPP` và `G74_B514_COUNT_RENDERER=ENABLED`. Nếu không khớp, server **không include** module hoặc CSS.
2. Người kiểm thử truy cập URL Web App TEST có query `g74CountTest=1`.
3. Bài thực đang hiển thị là B20 phiên bản biến thể; vào một trong `LV1-A`, `LV1-B`, `LV2-A`, `LV2-B`, `LV3-A`, `LV3-B`.

**Không bật hai Script Properties này trong project Apps Script gốc có MAIN đang dùng.** Trong Apps Script, các deployment cùng project thường dùng chung Script Properties, vì vậy chỉ được chạy trên **project TEST độc lập**.

## 4. Trình diễn đúng sáu dạng

- Đếm **12 con thỏ**.
- Chia **12 chiếc bút chì thành 4 nhóm, mỗi nhóm 3**, có ranh giới nhóm.
- So sánh **8 quả táo với 5 quả táo**, tách hai nhóm.
- Cộng **7+5 con thỏ** bằng hai nhóm, kết quả 12.
- Trừ **9−4 quả táo**: vẽ **9** quả, đánh dấu **4 quả bớt đi**, còn **5** — **không vẽ 13 quả**.
- Minh họa **bộ sách** một ảnh, **không hiển thị số lượng**.

Các ví dụ được ghi là **TEST – không chấm**, là bài minh họa kỹ năng chứ **không phải** các câu hỏi 30 câu B20 đã ký duyệt.

## 5. Tiêu chí QA

- Truy cập bình thường (không flag), sai lesson B21 hay view THEORY phải **không** mount.
- Đúng B20 và cả 3 cổng phải mount, không sửa thẻ câu hỏi hoặc giá trị ô trả lời cũ.

- Hình SVG phục vụ test có SHA metadata; những hình không được B.5.13 duyệt không được dùng để đếm.
- Khi module thử lỗi, bắt lỗi và giữ nguyên phần bài học cũ.

## 6. Cách triển khai và rollback

1. Sao chép nhánh TEST này sang **Apps Script project TEST riêng biệt**, không `clasp push` hoặc deploy vào project MAIN đang có học sinh dùng.
2. Xác nhận các tệp HTML, CSS, GS mới có mặt; chạy bản TEST **chưa bật cờ** để xác nhận không đổi UI.
3. Tại **Script Properties của project TEST riêng**, đặt đúng hai giá trị cờ ở mục 3; triển khai phiên bản Web App TEST.
4. Mở URL `.../exec?g74CountTest=1`, vào B20 một trong sáu lượt; kiểm tra vùng **THỰC HÀNH HÌNH ĐẾM · TEST** cuối phần câu hỏi. Chuyển dạng/màn hình; đối chiếu câu, đáp án và kết quả chấm của B20.
5. Truy cập URL `.../exec` không có query và bài khác; phải giữ nguyên.
6. **Rollback tức thì:** bỏ `G74_B514_COUNT_RENDERER` khỏi Script Properties của project TEST, refresh/reload trang; nếu cần, revert nhánh về B.5.13. Không cần sửa dữ liệu học sinh.
