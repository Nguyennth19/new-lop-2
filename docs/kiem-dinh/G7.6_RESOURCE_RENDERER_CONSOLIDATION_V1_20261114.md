- `du-lieu/g7-6/variant-public-envelope.schema.json`: định nghĩa bản chiếu dữ liệu câu hỏi *công khai* có `lessonId,questionId,variantId,typeId,mode,display,visualIntent,speech`.

- `qa/g7-6/resource-renderer-resolver.test.cjs`: xác minh SHA nguồn, số mục, chống rò trường `answer/answerKey/correctAnswer/solution/result` kể cả nested, từ chối hình chưa duyệt, từ chối bằng chứng count tự khai, chặn D10 và mốc kết quả đúng 1000 (4 cột).
- Public envelope **không phải API trusted server**. Backend phải tự quyết định quyền, giữ khóa đáp án riêng và chiếu public fields. Không gửi giáo án hoặc lời giải bị khóa cho client rồi chỉ ẩn bằng CSS/JS.
- Registry renderer tham chiếu P0.6; multi-family composer P0.6 chưa được chứng minh hỗ trợ 12 mode G7.4 qua E2E.
