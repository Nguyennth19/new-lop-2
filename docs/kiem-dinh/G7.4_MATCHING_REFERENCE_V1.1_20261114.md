## 3. Hợp đồng dữ liệu
```json
{
  "exerciseId": "MATCH_B20_TEST",
  "relationMode": "MIXED_RELATION",
  "leftItems": [
    {"id": "L1", "content": {"type": "MATH", "text": "2 + 2 + 2"}},
    {"id": "L2", "content": {"type": "TEXT", "text": "Lon sữa bò"}}
  ],
  "rightItems": [
    {"id": "R1", "content": {"type": "TEXT", "text": "Khối trụ"}},
    {"id": "R2", "content": {"type": "MATH", "text": "2 × 3 = 6"}}
  ]
}
```
`content.type`: TEXT / MATH / ASSET / MIXED. `assetId` được giải bằng callback `resolveAsset` của ứng dụng; chưa kết nối resolver G7.4 thực tế. Các ID là định danh opaque, không chứa khóa đáp án. Cấu hình từ 2 đến 8 cặp, quan hệ SINGLE_RELATION hoặc MIXED_RELATION.

**Cấm** `matchId`, `answer`, `answerKey`, `correctId` trong dữ liệu hiển thị. Đáp án phải thuộc bộ chấm tin cậy riêng. Không có `google.script.run`, không chấm tại client, không cấp sao/điểm hoặc ghi tiến độ.
