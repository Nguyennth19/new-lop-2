/* G5 – Bộ đếm thời gian tương tác THỰC (ước lượng từ hành động). * Không tăng số giây khi tab ẩn, app không có focus hoặc không có tương tác. * Thời gian này chỉ dùng thống kê; máy chủ vẫn tự chấm đáp án. */ const DEM_TUONG_TAC=(function(){ let last=null,total=0; function reset(){last=null;total=0;} function touch(){ const now=Date.now(); if(document.hidden||!document.hasFocus?.()){last=null;return;} if(last!==null){const gap=(now-last)/1000;if(gap>=0&&gap<=30)total+=gap;} last=now; } function seconds(){return Math.max(0,Math.min(1800,Math.round(total)));} document.addEventListener('visibilitychange',()=>{last=null;}); window.addEventListener('blur',()=>{last=null;}); return Object.freeze({reset,touch,seconds}); })();
